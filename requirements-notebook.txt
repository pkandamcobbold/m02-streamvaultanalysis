# brief asks to run from a clean clone.

#     pip install -r requirements.txt            # the analysis
#     pip install -r requirements-notebook.txt   # plus the notebook viewer
#
# WARNING, and the reason this file exists: on Python 3.15 this install FAILS,
# re-confirmed 2026-11-19. `jupyter` resolves to jupyterlab 4.x, which pulls
# jupyter-events, which requires PyYAML, which has no Python 3.15 wheel. pip
# resolves it to an sdist — so `pip install --dry-run` succeeds and tells you
# nothing — and the build then fails with "Failed building wheel for pyyaml".
# If that happens, the pipeline is unaffected: read the reports in reports/, or
# install this under Python 3.12 or 3.13 where PyYAML has wheels.
#
# It is pinned rather than left open so that a future resolution change is a
# visible edit to this file rather than a surprise.

-r requirements.txt
jupyter==1.1.1
